# Apex Interventional Psychiatry Landing Page

Marketing landing page for Apex Interventional Psychiatry (TMS + Spravato®), focused on treatment-resistant depression, anxiety, and OCD.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
